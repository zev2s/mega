# Страница с видео

Адаптивная страница на русском языке с видеоплеером MEGA и кнопкой для открытия видео.

## Включение публикации

В настройках репозитория откройте **Settings → Pages** и выберите **GitHub Actions** в поле **Build and deployment → Source**. После этого workflow автоматически опубликует содержимое папки `site` при каждом изменении ветки `main`.

Сайт будет доступен по адресу: https://zev2s.github.io/mega/
